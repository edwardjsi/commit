# AWS CloudTrail & KMS – Security Essentials

This folder covers two critical AWS security pillars:

- **CloudTrail** – Tracks *who did what* in your AWS account  
- **KMS** – Controls *how your data is encrypted and protected*

Security in the cloud is not optional —  
auditability and encryption are the minimum standards of production-ready systems.

- How KMS handles encryption and key control
- How both services work together in real-world environments
- Best practices used in production AWS accounts

---

## Why this matters

Most outages and breaches happen not because of EC2 or S3 —  
but because **logging, access control, and encryption were ignored**.

This documentation helps you avoid that mistake.
